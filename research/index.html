研究与论文

关注 GPU 的细粒度可观测性，以及采集机制与真实推理工作流之间的关系。

ISPA 2026已录用

Execution-Reference Encoding and Recovery-Aware Collection for GPU Profiling

Qirui Deng, Yongxian Fan, Yongwei Zhang, Zuwen Lai
School of Computer Science and Information Security, Guilin University of Electronic Technology

细粒度 GPU 追踪会产生大量记录，采集开销可能显著改变被观测任务。ERETrace 将执行参考编码与面向恢复的采集设计结合，在保留完整记录语义的条件下，降低完整推理请求的采集延迟与输出体积。

方法的三个组成部分

01 / Execution references

使用 SM / CTA 参考关系减少重复表示，在范围条件满足时使用窄字段，并保留精确恢复所需的信息。

02 / Checked fallback

不满足编码接受条件时保留 raw 记录。字段值、精度、顺序与执行归属保持可恢复，独立正确性运行检查无损性。

03 / Bounded collection

将参考编码放入有界异步采集流水线，协调编码、D2H 与文件输出，以完整请求成本评价系统收益。

实现与复现

运行环境

Linux / CUDA，基于 Neutrino 可编程探针。公开制品包含构建说明、补丁、工作负载入口与配置。

记录语义

默认细粒度记录包含每个 warp 的 start、elapsed 与 SM ID，以及执行归属信息。数据应能逐条精确恢复。

工程边界

主评估、NVBit / XTrace 适配和容量原型分别有各自配置与支持范围，具体条件见制品文档。

GPU 追踪的收益需要同时看语义、时间与空间。更小的文件不等于更快的 kernel；采集器的性能也不等于模型本身的原生推理性能。
