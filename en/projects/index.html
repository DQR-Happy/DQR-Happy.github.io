01 / GPU observability

ERETrace

ISPA 2026 · v1.0.0
CUDAC/C++Lossless tracingSystems research

Making fine-grained GPU traces practical.

Lossless execution-reference encoding, checked raw fallback, and bounded asynchronous collection reduce the cost of fine-grained tracing during complete inference requests.

  • SM / CTA references and exact recovery
  • Complete-request latency and trace-file evaluation
  • Reproduction configs, public data, and separate correctness checks

02 / Inference engineering

HeteroQuantServeBench

In development
PythonCUDA / TritonLLM inferenceBenchmarking

An evidence trail from kernels to serving.

An inference experimentation project targeting CUDA and Ascend/CANN. A web console connects model baselines, kernel substitutions, quantization, KV-cache policies, runtimes, and native inference engines to recorded runs.

  • Run configurations, execution evidence, and quality comparisons
  • Memory, dataflow, and kernel diagnostics linked to runs
  • Active development; module support is documented in the repository
